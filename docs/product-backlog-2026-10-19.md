# 제품 개선 후보와 협업 방향 — 2026-10-19

## 사용자와 합의한 방향

- 현재 우선순위는 콘텐츠를 충분하고 정확하게 갖추는 것과 기존 기능의 완성도다. 특히 멤버 조합 찾기를 더 발전시키고 싶다는 의향이 있다. 구체적인 구현 범위는 아직 정하지 않았다.
- 다양한 공유가 필요하다는 방향에는 동의했지만, 어떤 결과물을 어떤 방식으로 공유할지는 함께 구체화한다.
- 홍보·대회·크리에이터 협업은 후속 과제로 보류한다. 이전 조사에서 제시한 30일 홍보 계획은 실행 계획으로 채택한 것이 아니다.
- Instagram은 이미 수집이 시작됐고 Claude Code가 화면·뷰어까지 구현 중이다. 이전 조사 보고서의 ‘Instagram 도입을 뒤로 미루자’는 가정을 현재 로드맵에 적용하지 않는다. 정확한 운영 상태·남은 SQL/토큰/수집 과제는 최신 CHANGELOG의 인스타 항목을 따른다.

## 다음에 함께 구체화할 후보

| 영역 | 먼저 확인할 것 | 결정할 것 |
|---|---|---|
| 멤버 조합 찾기 | 기존 조합 검색·동반 출연 판정·필터·결과·공유를 실제 사례로 체험 | 가장 거슬리는 한 흐름과 첫 개선 범위 |
| 콘텐츠 충실도 | 원하는 멤버/조합에서 누락·오분류·편중이 있는지 | 수집 보강과 검색/표시 수정 중 실제 원인에 맞는 작업 |
| 다양한 공유 | 이미 가능한 아티스트·영상·조합·컬렉션 공유와 링크 미리보기 | 조합 결과, 발견 경로, 소식 등 추가 공유 단위 및 받는 사람의 화면 |
| 첫 사용 경험 | 최근 온보딩 개선 후 실제 사용 흐름 | 추가 안내가 필요한지; 새 선택 화면은 확정 사항 아님 |

‘최애에서 시작’, ‘발견 경로 공유 카드’, ‘왜 연결됐는지 설명’, ‘공유 링크 미리보기 개선’은 검토 후보다. 기존 구현을 먼저 확인하고 중복 개발을 피한다. 기능 수를 늘리기보다 사용자가 원하는 콘텐츠에 도달하는지를 기준으로 판단한다.

## 사용자와 작업하는 방식

사용자는 아이디어나 느낌부터 이야기할 수 있다. 에이전트는 이를 구체적인 사례와 작은 선택지로 바꾸고 권장 방향과 이유를 쉽게 설명한다. 사용자가 제품 방향을 정하고 에이전트가 합의한 구현을 실행한다. 모든 것을 사용자가 기술적으로 명세할 필요도, 에이전트가 전부 대신 결정할 필요도 없다. 설명은 쉬운 한국어로, 코드·CHANGELOG는 다른 Claude Code/Codex가 이어서 작업하기 좋은 정확한 표현으로 남긴다.
